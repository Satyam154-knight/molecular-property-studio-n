MOLECULAR PROPERTY STUDIO — CLEAN REBUILD

1. Create a NEW folder named molecular_property_studio_clean.
2. Put app.py and requirements.txt in it.
3. Open this folder in VS Code.
4. In Terminal, run:
   python -m pip install -r requirements.txt
   python -m streamlit run app.py

This is a clean rebuild; do not run the old app.py from the old folder.
